# My VPN App

Open-source VPN client for Android and iOS.

## Goals

- AmneziaWG support
- Xray (VLESS + REALITY) support
- Hysteria 2 support
- Import via QR code, file, or link
- Keys stored only on device
- Open source under GNU GPL v3.0

## Project Status

Work in progress.

## Planned roadmap

1. Server setup
2. Android MVP
3. Android protocol integrations
4. iOS MVP
5. iOS protocol integrations
6. Testing and release
